## 📖 Project Overview

The goal of this project is to design and develop an **ERP system for a gas station**, providing tools to manage different aspects of the business through a centralized platform.

The project includes:
- Requirements analysis
- System design
- Project organization and management
- Development and implementation

We adopted an **Agile development methodology**, using sprint planning and task management throughout the project lifecycle.
